# Tic Tac Toe Game

A simple web-based Tic Tac Toe game built with HTML, CSS, and JavaScript. This project allows two players to play the classic game in a browser.

## Features

- 3x3 grid interface
- Two-player mode (O and X)
- Win detection and draw handling
- New game and reset controls

## File Structure

- `gam.html`: Main HTML file containing the game layout.
- `ga.css`: Styles for layout and design.
- `game.js`: JavaScript logic for gameplay, win checking, and controls.

## Usage

1. Open `gam.html` in a web browser.
2. Click on the grid cells to take turns as O and X.
3. Use the "New Game" or "Reset Game" buttons to restart.
